# Concept art provenance

Created on 2026-09-14 for the future-release optional town side-quest design using
the built-in `image_gen` tool, not the CLI/API fallback. These selected original
PNG outputs are preserved without image edits. They illustrate mood, composition,
acting and lighting; they are not implemented gameplay or approved final assets.
Production remains subject to the design specification and actual town geometry.

## Saved deliverables

- `era-cinematic-concepts.png`: four cinematic keyframes, 1586 × 992.
- `horse-and-dog-concepts.png`: companion animal-event keyframes, 1907 × 825.

The first generation used local game screenshots `aviation-complete-detail.png`
and `contemporary-complete-detail.png` from the issue #41 browser verification as
style and architecture references only (not edit targets). The second generation
used the first generated four-panel sheet as its style reference. No CLI model,
seed or API parameters are claimed; the built-in tool selected those internally.

## Inspection notes

Both selected sheets were visually inspected. The intended subjects and labelled
era/event compositions are readable. The animal sheet is more illustrative and
detailed than the existing runtime models; do not interpret it as permission to
introduce photorealistic fur or expensive runtime hair. Final horse/dog animation
must be assessed as moving 3D geometry with grounded contacts; a still concept
image does not prove correct anatomy, gait, collision or performance.

All future implementations must keep the existing building footprints and
unlock eras: the full horse field arrives in Industrial and the public park in
Motor Age. The earlier Frontier introduction uses the existing stables.
